Elang Ridge Run — Volcano Courier: a 3D Three.js flight game. Fly the Elang-7 bush plane through 8 glowing rings over the Nusa archipelago, past the smoking volcano, then land gently on Runway 18 before the fuel runs out. Chase and cockpit cameras, dense flight instruments, fuel and stall management, rough-field landings, and a full mission score.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/game/ in desktop Chrome. Fly with **W/S** throttle, **arrow keys** pitch/roll, **A/D** rudder, **G** gear, **C** camera, **P** pause, **M** mute — or drag with the mouse to steer. Press **Enter** to start.
